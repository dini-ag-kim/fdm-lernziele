# Worksheet Learning Objectives	
	
Column A	ID of the Learning Objective
Column B	Subject Name
Column C	Subject ID
Column D	Name of the topic
Column E	ID of the topic
Column F	Start of the Learning Objective
Column G	Learning Objective verb
Column H	Content of the Learning Objective
Column I	Learning level according to Bloom
Column J	Form of Adaption
Columnn K-N	Suitability for the target group  (BA=Bachelor students, MA=Master students, ECR= Early Career Researcher, DS=Data Steward)
Columnn O-R	Knowledge dimensions addressed by the learning objective. (FK=factual knowledge, CK=conceptual knowledge, PK=procedural knowledge, MK=metacognitive knowledge)
Column S	Whole learning objective (start, verb and content) for copy and paste
	
## Learning Objectives	

A learning objective is always put together out of Columns F to H, these containing a recurring introduction, a variable action component (what type of action is addressed by the learning objective) and a variable content component (what thematic content is addressed by the learning objective).	
Column S already provides the interconnected content from Columns F through H; that is, the formulation of a complete learning objective consisting of an introduction, an action component, and a content component.	
	
The contents of the worksheet Learning Objectives can be filtered be using the filter options of the headings.	
	
## Explanation of the assignment of Bloom's level.	

Assignment is made on the basis of the verbs used, as follows:	
- to name	1
- to explain	2
- to apply	3
- to analyse	4
	
In the current version of the LOM-OMRD [as of November 5, 2026], the learning objectives have not yet been assigned to knowledge dimensions.
